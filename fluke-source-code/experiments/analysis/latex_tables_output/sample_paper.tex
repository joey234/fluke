\begin{abstract}
We present comprehensive evaluation results of Large Language Models (LLMs) on the FLUKE benchmark suite, 
with particular emphasis on the performance of frontier models GPT-5 and DeepSeek R1. Our analysis covers 
four core NLP tasks: Coreference Resolution, Dialogue Understanding, Named Entity Recognition, and Sentiment 
Analysis. Results demonstrate that GPT-5 achieves consistent improvements over GPT-4o, with an average 
performance gain of 2.77\%, while DeepSeek R1 shows competitive performance on coreference resolution (81.48\%).
\end{abstract}

\section{Introduction}

The FLUKE (Few-shot Language Understanding and Knowledge Evaluation) benchmark provides a comprehensive 
evaluation framework for assessing LLM capabilities across diverse linguistic tasks and modifications. 
This report presents results from evaluating 9 LLMs, including frontier models GPT-5 and DeepSeek R1.

\section{Discussion}

\subsection{Key Findings}

\begin{enumerate}
    \item \textbf{GPT-5 Improvements}: GPT-5 consistently outperforms GPT-4o across all tasks, 
          with the most significant improvement in coreference resolution (+9.46\%).
    
    \item \textbf{DeepSeek R1 Promise}: Despite limited evaluation, DeepSeek R1 shows competitive 
          performance on coreference resolution, warranting further investigation.
    
    \item \textbf{Task Difficulty}: Clear hierarchy emerges with NER as most challenging (<10\% avg), 
          followed by coreference (∼50\% avg), then dialogue and sentiment (>80\% avg).
    
    \item \textbf{Modification Sensitivity}: Models show dramatic performance drops on linguistic 
          modifications, indicating potential brittleness to input variations.
\end{enumerate}

\subsection{Limitations}

\begin{itemize}
    \item Limited evaluation of DeepSeek R1 (only coreference task)
    \item Low NER scores suggest potential evaluation methodology issues
    \item Modification tests use small sample sizes (100 examples)
\end{itemize}

\section{Conclusion}

The FLUKE benchmark evaluation reveals GPT-5 as a consistent improvement over GPT-4o, while DeepSeek R1 
shows promise as a competitive alternative. However, all models demonstrate sensitivity to linguistic 
modifications, highlighting the need for more robust language understanding capabilities. Future work 
should focus on expanding DeepSeek R1 evaluation and investigating the unexpectedly low NER performance 
across all models.
